# Fragmented Paths

## Description
Fragmented Paths is an interactive web project that explores nonlinear navigation and disrupted agency. The user moves through a series of pages where links sometimes lead forward, backward, or nowhere.

## How to Experience It
Click through the pages and follow different paths. Some links may loop or break expected navigation.

## Concept
This project is about:
- loss of control
- confusion in digital spaces
- fragmented identity

The structure resists clear progression and encourages wandering.
